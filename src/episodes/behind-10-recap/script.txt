عرفت دلوقتي إيه اللي بيحصل بعد ضغطة اللايك؟ الطلب سافر، والـ API وصّله للـ Server. الـ Server سأل الـ Cache الأول، ولو مالقاش الرد راح للـ Database. والـ Database استخدمت Index ولقت الصف في لحظة. والـ Event Loop خلّى الشاشة شغالة طول الوقت. وكل ده متحسوب بالـ Big-O عشان يستحمل ملايين الناس. المرة الجاية لما تفتح أي تطبيق، افتكر الرحلة دي.
