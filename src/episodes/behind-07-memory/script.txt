ليه التطبيق بيهنج لما تفتح عليه حاجات كتير؟ لأن ذاكرة الموبايل محدودة. الـ Memory فيها منطقتين. الـ Stack: سريع ومنظم، وبيشيل المتغيرات الصغيرة. والـ Heap: كبير، وبيشيل الأشياء الكبيرة، والمتغير بيشاور عليها. لو التطبيق فضل يحجز في الـ Heap ومايمسحش اللي خلّص منه، المساحة بتخلص والتطبيق يقفل. واسمها Memory Leak. الحلقة الجاية: ليه التطبيق مابيهنجش وهو بيحمّل حاجة تقيلة؟
