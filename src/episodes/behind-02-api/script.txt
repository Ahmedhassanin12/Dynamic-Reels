ليه تطبيق الموبايل مستحيل يكلم الداتابيز مباشرة؟ لو عملت كده، أي حد يقدر يفك التطبيق ويعدل رصيده ويسرق بيانات المستخدمين في ثانية! عشان كده اتعمل الـ API. وده مش مجرد جرسون بينقل طلبات، ده حارس أمن ومترجم في نفس الوقت. لما تطلب بيانات، التطبيق بيبعت Request شايل بيانات بصيغة JSON. الـ API بيفحص الـ Headers، وبيتأكد إن الطلب مش هجوم DDoS عبر حاجة اسمها Rate Limiting، يعني بيسمحلك مثلاً بمية طلب في الدقيقة بس لكل عنوان IP. كمان بيعقّم الطلب عشان يمنع ثغرات الـ SQL Injection. ولما السيرفر يخلص، الـ API بيرجعلك بكود حالة واضح: 200 OK لو العملية نجحت، 401 لو مش مسجل دخول، أو 500 لو السيرفر وقع من الضغط! الخلاصة: الـ API هو خط الدفاع الأول اللي بيحمي النظام وبيوحد لغة التواصل بين الآيفون والأندرويد والويب. طب بعد ما الـ API سلّم البيانات بأمان، إزاي الداتابيز بتنظم ملايين الصفوف دي بدون لخبطة؟ ده موضوع الحلقة الجاية: قواعد البيانات والجداول.
