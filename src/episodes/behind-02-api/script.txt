التطبيق عمره ما بيكلّم الـ Database مباشرة. بيعدّي على وسيط اسمه API. تخيّل مطعم: انت الزبون، والمطبخ هو الـ Server، والـ API هو الجرسون. بتطلب من الجرسون، وهو يوصّل الطلب للمطبخ ويرجعلك الأكل. ما تعرفش المطبخ جواه إيه، وما تحتاجش تعرف. كل اللي عليك إنك تطلب بالطريقة الصح. الحلقة الجاية: المطبخ بيحفظ المكونات فين؟ الـ Database.
